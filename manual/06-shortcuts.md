# Keyboard shortcuts

**Super** is the Windows key. Every shortcut can be changed in **Desktop Settings → Keyboard**.

## The basics

| Shortcut | Does |
|---|---|
| Super | App menu |
| Super+T | Terminal |
| Super+W | Browser (LibreWolf) |
| Super+E | Files |
| Super+C | Code editor (VSCodium) |
| Super+Q | Close the window |
| Super+L | Lock |
| Super+Shift+L | Sleep |
| Ctrl+Alt+Del | Log out, restart, shut down |
| Ctrl+Shift+Esc | Task Manager |

## Windows

| Shortcut | Does |
|---|---|
| Alt+Tab | Switch windows |
| Super+Tab | Switch workspaces |
| Super+M | Minimise |
| Super+Alt+M | Bring back the last minimised window |
| Super+Alt+F | Maximise |
| Super+F | Fullscreen |
| Super+Alt+Space | Floating or tiling, for every window |
| Super+P | Keep the window on every workspace |
| Super+Z / Super+X (hold) | Move / resize with the mouse |

## Workspaces

| Shortcut | Does |
|---|---|
| Super+1...0 | Go to workspace 1-10 |
| Super+Alt+1...0 | Move the window there and follow it |
| Super+Shift+1...0 | Move the window there and stay |
| Super+scroll, Super+PageUp/PageDown | Next / previous workspace |

## Screenshots and tools

| Shortcut | Does |
|---|---|
| Print | Screenshot of an area |
| Super+Shift+S | Screenshot with the screen frozen |
| Ctrl+Alt+R | Record the screen |
| Super+Shift+C | Colour picker |
| Super+V | Clipboard history |
| Super+. | Emoji |

## Media and notifications

| Shortcut | Does |
|---|---|
| Ctrl+Super+Space | Play / pause |
| Ctrl+Super+= / - | Next / previous track |
| Super+Shift+M | Mute |
| Super+K | Notifications and quick settings |
| Ctrl+Alt+C | Clear notifications |
| Ctrl+Super+Alt+R | Restart the shell, if it misbehaves |
