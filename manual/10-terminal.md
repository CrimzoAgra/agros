# The terminal

**Super+T** opens the terminal (foot), running the fish shell, with Caelestia's prompt and colours.

## Handy commands

| Command | Does |
|---|---|
| `fetch` | The AgrOS logo spinning in 3D, with your system's details. Press any key to stop |
| `fastfetch` | The same details, without the spin |
| `btop` | Task Manager |
| `paru -S <name>` | Install an app |
| `update-apps` | Update everything now |
| `agros-personal` | Restore your accounts from the pen drive |
| `agros-personal --save` | Save your accounts to the pen drive |
| `dotfiles-check` | Check that everything is working (see [Troubleshooting](14-troubleshooting.md)) |

## Tools that come with it

`eza` (a better `ls`), `zoxide` (`z <folder>` jumps to folders you've visited), `bat` (a better `cat`), `ripgrep`
(`rg`, fast search), `lazygit`, `trash-cli` (`trash` instead of `rm`), `micro` (a simple text editor) and `jq`.
